BollyScapes – Discover Places. Create Memories.

BollyScapes is a responsive destination discovery platform designed to help users explore fascinating tourist attractions around the world. From iconic landmarks and natural wonders to beautiful beaches and historical sites, BollyScapes makes discovering your next adventure easier.

It is my final project for the REV COHORT after three months of training in Frontend Web Development at TechUp Academy.

Features

- Responsive Design: Optimised for desktop, tablet and mobile devices.
- Destination Discovery: Explore 12 fascinating destinations from different parts of the world.
- Destination Details: View information about attractions, including their locations, categories, descriptions and entrance fees.
- Search and Explore: Find destinations easily.
- Destination Enquiry: Select a destination and enquire about visiting it.
- Interactive FAQ: Expand and collapse frequently asked questions.
- Form Validation: Provides feedback when users submit incomplete or invalid enquiry details.
- Light and Dark Mode: Switch between light and dark themes.
- Interactive User Interface: Smooth navigation, popups and interactive elements.

Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- Vite

Project Overview

BollyScapes is organised into reusable React components to make the application easier to manage and maintain.

The website includes:

- Navbar
- Home / Hero
- About
- Destinations
- FAQ
- Contact / Enquiry Form
- Footer

Design

The design uses a clean and modern travel-inspired interface.

- Light Mode: Cream, white and blue.
- Dark Mode: Night navy, warm white and primary blue.

The interface is designed to provide a consistent experience across different screen sizes.

Project Scope

BollyScapes is a frontend-only project. Destination enquiries and form submissions demonstrate client-side interactions. No backend, database or actual payment processing is integrated.

Project Goal

The goal of this project was to display my frontend development skills by building a responsive, interactive website using React and Tailwind CSS while practising component reusability, state management, event handling, form validation and theme switching.
